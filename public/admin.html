File format

One student per row. The first row must be the column headings. Save the sheet as Excel (.xlsx) or CSV (.csv), up to 5 MB and 20,000 rows. Old .xls files must be saved again as .xlsx.

ColumnNeeded?Headings that are recognisedWhat goes in itExample

  • Columns can be in any order, and extra columns (Sl No, Gender and so on) are ignored.
  • A title row above the headings is fine. Every sheet in an Excel file is read.
  • A row is skipped if its ERP ID is invalid, its name is empty, or the ERP ID already appeared. The result shows which rows were skipped and why.
  • No headings at all? Then the columns are read in this order: ERP ID, Name, Branch, Phone, Email, Section.

How the list is used

A student types an ERP ID and the name and branch are filled in from this list and cannot be changed. If the list has the leader's email, that email is used too. ERP IDs that are not on the list are refused.

Applies only to students whose phone is on the list. Makes it harder to register in someone else's name, but a student whose number changed will need your help.

A 6 digit code is emailed before payment. With the list on, it goes to the email the college has for that ERP ID, so nobody can register as someone else. Leaders also get an email when their registration is received, confirmed or rejected.

Use Edit on a row to correct a student after a bulk upload.
